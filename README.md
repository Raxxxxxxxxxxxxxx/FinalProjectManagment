# منصة توريد

منصة عربية تربط أصحاب المشاريع الصغيرة والمتوسطة بالمورّدين، مبنية باستخدام
Django وHTML وTailwind CSS وJavaScript.

## التشغيل محلياً

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
npm install
npm run css:build
python manage.py migrate
python manage.py seed_demo --reset
python manage.py runserver
```

ثم افتح `http://127.0.0.1:8000`.

يفحص `http://127.0.0.1:8000/health/` اتصال قاعدة البيانات. لإعادة بيانات
المناقشة إلى نقطة البداية في أي وقت:

```bash
python manage.py seed_demo --reset
```

في بيئة الإنتاج اضبط `DJANGO_DEBUG=0` و`DJANGO_SECRET_KEY` و
`DJANGO_ALLOWED_HOSTS`. عند تعطيل وضع التطوير تُفعّل إعدادات HTTPS والكوكيز
الآمنة وHSTS تلقائياً.

حسابات التجربة (كلمة المرور للجميع: `Demo12345!`):

- صاحب مشروع: `owner_demo`
- مورّد: `supplier_demo`
- مورّد ثانٍ للمقارنة: `supplier2_demo`
- إدارة: `admin_demo`

## التقنية

- Django 5.2
- SQLite في بيئة التطوير
- Django Templates
- Tailwind CSS 3.4 مبني محلياً إلى `static/css/tailwind.css` دون CDN
- JavaScript بدون إطار عمل
- Django i18n للواجهة العربية والإنجليزية
- ثيم فاتح وداكن وفق هوية جامعة الشام
- CSP وReferrer-Policy وPermissions-Policy وصفحات أخطاء مخصصة

## دورة العمل المنفذة

1. يدير المستخدم ملف منشأته، وتراجع الإدارة توثيق المورد ووثيقته الخاصة.
2. يدير المورد الموثق كتالوج منتجاته وخدماته.
3. ينشر صاحب المشروع طلب عرض سعر ببنود ووحدات ثابتة قابلة للترجمة.
4. يرسل المورّدون الموثقون عروضهم، ويمكن تعديل العرض أو سحبه قبل الموعد.
5. يقارن المالك العروض بدرجة استشارية شفافة: السعر 50%، المدة 30%،
   وتقييم المورد 20%، ثم يعتمد اختياره بنفسه.
6. ينشأ أمر شراء مع نسخة ثابتة من البنود والسعر ومدة التسليم.
7. يؤكد المورّد الأمر، ثم يبدأ التجهيز بعد تحقق شرط الدفع.
8. يسجل المورّد الشحن والتسليم، ويؤكد صاحب المشروع الاستلام.
9. يتاح تقييم المورّد بعد اكتمال الطلب.
10. تُسجّل الحالات وتُرسل إشعارات بسياق تاريخي ثابت.
11. تعرض التقارير مؤشرات حسب الدور ويمكن تصدير الأوامر المصرح بها إلى CSV.

الصفحة الرئيسية تعرض أرقاماً محسوبة من قاعدة البيانات، ومنها وفر تقديري
مقارن بمتوسط عروض الطلبات المتعاقد عليها. هذه مؤشرات تشغيلية وليست تقريراً
محاسبياً.

الدفع الحالي يدعم التحويل البنكي اليدوي والدفع عند الاستلام. اعتماد التحويل
محصور بإدارة المنصة. ربط بوابة دفع خارجية يحتاج اختيار المزوّد ومفاتيح API
خاصة ببيئة التشغيل، ولا تُخزّن المنصة بيانات بطاقات مصرفية.

## بيانات المناقشة

يبني `seed_demo --reset` أربع حالات معروفة:

- طلب مفتوح بعرضين للمقارنة والاختيار.
- أمر شراء مشحون بدفع عند الاستلام.
- طلب مفتوح بعرض واحد.
- أمر مكتمل بتحويل مؤكد وتقييم.

كما ينشئ أربعة عناصر كتالوج وحسابات demo موثقة. يحذف reset بيانات هذه
الحسابات التجريبية فقط، ويرفض الأمر العمل عندما يكون `DEBUG=False` حتى لا
تنشأ كلمات مرور demo الثابتة خارج بيئة التطوير.

## الجودة والتحقق

نجحت النسخة الحالية في **52/52 اختباراً آلياً**. تشمل التغطية إعادة فحص نشاط
المورد وتوثيقه لحظة اعتماد العرض، ومنع نموذج ملف قديم من استعادة توثيق ألغته
الإدارة، وتحييد صيغ ومحارف التحكم في CSV، ومنع seed التجريبي خارج `DEBUG`.

```bash
python manage.py test
python manage.py check
python manage.py makemigrations --check --dry-run
```

## الهوية واللغات

- يمكن تبديل اللغة من زر `EN / عربي` في رأس الموقع، ويتغير الاتجاه تلقائياً
  بين RTL وLTR.
- يمكن تبديل الوضع الفاتح والداكن من زر الثيم، ويحفظ المتصفح الاختيار محلياً.
- لاستبدال الشعار المؤقت بالشعار الرسمي، استبدل الملف
  `static/images/university-logo-placeholder.svg` مع الحفاظ على الاسم، أو عدّل
  مسار الصورة في `templates/base.html`.
- بعد تعديل نصوص الترجمة شغّل:

```bash
python manage.py makemessages -l ar
python manage.py compilemessages
```
